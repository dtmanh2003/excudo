# 小話の5秒表示と色の確認

## モデルを使わない確認

`uv run python scripts/story_display_demo.py`

- 待機の小話はシアン色で、Excudo：「…」の形で折り返される。
- 3秒後に本文受信へ変わり、同じ物語の受信開始の一言が出る。
- その一言は本文受信の開始から5秒で消える。本文は12秒間受信し続ける。
- 画面の横幅を狭めても小話が折り返され、消えたあとに残骸がない。

## 実モデルを使う確認

`uv run main.py` で起動し、通常モード（/fast off）で以下を送る。

「Pythonの歴史を、主な出来事と背景も含めて詳しく説明してください。ツールは使わないでください。」

- 思考が30秒を超えて小話が表示された依頼で確認する。
- 待機中はシアン色の小話、本文開始時は受信開始の一言へ変わる。
- 本文の受信が5秒以上続くと、一言だけが消え、本文と状態表示は続く。
- 短い回答ですぐ完了する場合は、完了と同時に消える。
- Ctrl+C、通常の/think、入力への復帰が従来どおり。

Windows実端末で、モデル接続なしのデモを使い、受信開始の一言が5秒で消えることと、小話の色を確認済み（ユーザー確認）。
Mac/Linux実端末の目視は未実施。今回の変更は#49を含まない。
