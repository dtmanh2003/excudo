# 思考表示の実機確認

## 固定デモ（AI送信なし）

`uv run python scripts/ui_debug_demo.py` で起動し、`layout` と送る。
短い固定デモではプレビューの条件未満なので、文字数・時間だけが表示されることを確認する。長い思考では、最初の思考文字の受信から10秒以上かつ500文字以上の両条件を満たすと最新1行が表示され、本文開始時に消える。
回答後の案内から `/think` を送ると、思考全文が薄く表示される。`/new` 後には表示できないことを確認する。
`resize` の待機中に端末サイズを変え、Ctrl+Cで止めても入力に戻れることを確認する。

## 実モデル

`uv run main.py` で起動し、`Pythonの歴史を詳しく説明してください。ツールは使わないでください。` を送る。
最新1行・本文開始時の消去・回答後の秒数と文字数・`/think` 全文表示を確認する。
別の質問を送ると前の思考は消え、`/new` と再起動でも消えることを確認する。
再度同じ質問を送り、思考中にCtrl+Cで停止して `/think` で受信済みの部分を表示できることを確認する。
太字・表・コード、日本語入力、Tabによる既存補完も通常どおり動くことを確認する。

思考が履歴やセッションへ混入しないことは、記録用モデルと実セッション保存を通す自動テストでも確認する。
実端末の描画・IMEの目視確認と自動テストの結果は分けて記録する。

## 表示の追加確認

- 長い思考の1行では末尾が見え、新しい文字が届くと表示が進む。狭い端末でも1行に収まる。
- Ctrl+Cで止めた後の案内と `/think` の見出しに「途中まで」が付く。正常終了には付かない。
- `/think` の全文の前後に薄い区切りがあり、終了位置が分かる。
- `/new` 後は思考本文と「途中まで」の状態の両方が消える。

## 思考のメモと待機中の一言

- 回答後の案内と `/think` の見出しが「思考のメモ」と表示される。
- 全文の最後に「ここまで。回答までの寄り道でした。」の薄い区切りが表示される。
- 思考の受信開始から30秒前後で、状態バーとは別の領域に一言が出て次の更新まで残る（以降30秒ごとに更新）。
- 一言が思考本文・`/think` の全文に混入しない。本文開始時には同じ物語の受信用台詞へ切り替わり、完了・停止で消える。待機の小話が表示されなかった短い依頼には受信用台詞も出さない。
- 幅の狭い端末では小話が複数行に折り返され、十分な高さがあれば末尾まで読める。文字数・時間の状態バーは1行のまま。画面が低い場合は表示量を抑え、広げると小話の全文が戻る。

## つながる小話

30・60・90・120秒で同じテーマの一言が順に続き、次の30秒の更新までは文が変わらないことを確認する。次の依頼では直前とは別の組が選ばれる。小話はモデルの進捗説明ではなく、思考全文にも含まれない。タイミングと選択の検証は自動テストで時計を進めて行うため、長い質問を何度も送る必要はない。

## プレビューの表示条件

10秒未満で500文字以上の場合も、10秒以上で500文字未満の場合も、原文のプレビューは出さない。両方の条件を満たしたら表示する。条件未満の思考も `/think` で全文を確認でき、`/new` 後には消える。境界値は時計を進める自動テストで確認し、長い質問を繰り返し送る必要はない。

## 長い待機の物語

各物語は30秒から240秒まで8段階で続く。240秒を超えたら同じ物語専用の余話に進み、別のテーマには切り替わらない。20種類すべての切替は自動テストで時計を進めて確認する。小話は表示用の創作で、モデルの作業状況や残り時間を表すものではない。

待機・受信の台詞は通常の明るさで `Excudo：「…」` と表示し、台詞内の「 」は『 』にする。思考原文のプレビューは薄いまま。全20種類の30分相当の切替と狭い幅・リサイズ・承認待ち・停止は、自動テストでも確認する。
